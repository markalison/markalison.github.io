Nmap service enumeration

Solution to Network Enumeration with Nmap (section 6/12) Service Enumeration on Hack The Box Academy.

The command

In order to capture the flag for this module, run a full port scan with service version detection and default scripts: 

nmap -sV -sC -p- TARGET_IP

What the flags do

  • -sV — probe open ports for service and version info
  • -sC — run default NSE scripts against discovered services
  • -p- — scan all 65535 ports instead of only the top 1000

The combination of version detection and scripting is what surfaces the flag. The default scripts include banner grabbing and protocol-specific enumeration that pull details a plain port scan would miss.
